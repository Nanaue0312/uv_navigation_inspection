# 新增功能：图表显示模式选择

**日期**: 2025-12-18  
**版本**: v1.1.0  
**功能**: 散点图模式支持

---

## 📊 功能概述

用户现在可以在**三种不同的图表显示模式**之间自由切换，以更好地可视化和分析数据：

### 1. **📈 折线图模式** (默认)
- **特点**: 使用平滑的线条连接数据点
- **适用场景**: 查看数据趋势和变化轨迹
- **显示效果**:
  - 理论值：实线
  - 实际值（算法输出）：虚线
  - 误差图：紫色线条 + 黑色拟合曲线

### 2. **⚫ 散点图模式**
- **特点**: 只显示离散的数据点，不绘制连线
- **适用场景**: 
  - 数据点较少时更清晰
  - 需要精确查看每个测量点
  - 识别异常值或离群点
- **显示效果**:
  - 理论值：圆形标记点 (size=6)
  - 实际值：X形标记点 (size=6)
  - 误差图：紫色散点

### 3. **📊 折线+散点模式**
- **特点**: 同时显示线条和标记点
- **适用场景**: 需要同时看到趋势和具体数据点位置
- **显示效果**:
  - 线条和标记点的组合
  - 最直观但信息量最大

---

## 🎯 使用方法

### 在 Streamlit 应用中选择模式

1. 打开应用并上传数据文件
2. 在左侧边栏找到 **"📊 图表显示模式"** 部分
3. 选择您喜欢的显示方式：
   - 📈 折线图
   - ⚫ 散点图
   - 📊 折线+散点
4. 所有标签页中的图表会**实时更新**为选中的模式

## 🔧 技术实现

### 修改的文件

#### 1. `src/visualizer.py`
- **`plot_comparison()` 函数**:
  - 添加 `plot_mode` 参数（默认值: `'lines'`）
  - 支持三种模式: `'lines'`, `'markers'`, `'lines+markers'`
  - 根据模式动态设置 `line` 和 `marker` 属性

- **`plot_error()` 函数**:
  - 添加 `plot_mode` 参数
  - 散点图模式下不显示拟合曲线（移动平均线）
  - 保留误差上下限线显示

**示例代码**:
```python
# 使用折线图模式
fig = plot_comparison(df, 'timestamp', 'gt_distance', 'algo_distance',
                     'Ground Truth', 'Algorithm', 
                     'Distance Comparison', 'Distance (m)', 
                     plot_mode='lines')

# 使用散点图模式
fig = plot_comparison(df, 'timestamp', 'gt_distance', 'algo_distance',
                     'Ground Truth', 'Algorithm', 
                     'Distance Comparison', 'Distance (m)', 
                     plot_mode='markers')

# 使用组合模式
fig = plot_comparison(df, 'timestamp', 'gt_distance', 'algo_distance',
                     'Ground Truth', 'Algorithm', 
                     'Distance Comparison', 'Distance (m)', 
                     plot_mode='lines+markers')
```

#### 2. `app.py`
- **添加绘图模式选择器** (第46-56行):
  ```python
  plot_mode = st.radio(
      "选择显示方式",
      options=['lines', 'markers', 'lines+markers'],
      format_func=lambda x: {
          'lines': '📈 折线图', 
          'markers': '⚫ 散点图', 
          'lines+markers': '📊 折线+散点'
      }[x],
      index=0
  )
  ```

- **更新所有图表调用**:
  - 所有 `plot_comparison()` 调用添加 `plot_mode=plot_mode`
  - 所有 `plot_error()` 调用添加 `plot_mode=plot_mode`
  - 共更新 **12个图表调用**

## 📈 标记点样式设置

### Ground Truth vs Algorithm Output

| 显示类型 | 理论值 (GT) | 实际值 (Algo) |
|---------|------------|--------------|
| **折线图** | 实线 (width=2) | 虚线 (dash, width=2) |
| **散点图** | 圆形标记 ● | X形标记 ✕ |
| **标记大小** | size=6 | size=6 |

### 误差图样式

| 模式 | 误差点 | 拟合曲线 | 上下限线 |
|------|--------|---------|---------|
| **折线图** | 紫色线 (width=1) | 黑色线 (width=2) | 红/蓝虚线 |
| **散点图** | 紫色点 (size=6) | ❌ 不显示 | 红/蓝虚线 |
| **组合模式** | 紫色线+点 | 黑色线 | 红/蓝虚线 |

## 💡 设计考虑

### 为什么散点图模式不显示拟合曲线？

拟合曲线（移动平均线）的目的是**平滑数据并显示趋势**。在散点图模式下：
- 用户关注的是**离散的数据点**而非趋势
- 添加拟合曲线会使图表变得混乱
- 如果需要同时看趋势和数据点，应使用"折线+散点"模式

### 图表交互性

所有模式都保留 Plotly 的交互功能：
- ✅ 鼠标悬停查看数值
- ✅ 缩放和平移
- ✅ 图例点击隐藏/显示曲线
- ✅ 下载图表为PNG
