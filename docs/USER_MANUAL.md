# 紫外导航数据分析软件 - 用户使用说明书

## 1. 软件简介
**紫外导航数据分析软件 (UV Navigation Inspection Tool)** 是一款专为评估紫外引导着舰算法性能而设计的可视化分析工具。通过加载仿真或实测产生的 JSON 数据文件，软件能够直观地展示算法输出与真值（Ground Truth）的对比，计算误差指标，并辅助工程人员快速定位算法问题。

## 2. 软件运行
### 2.1 启动方式
软件提供独立可执行程序（.exe）版本，无需安装 Python 环境即可运行。
1. 找到 `uv_navigation_inspection.exe` 文件。
2. 双击运行。
3. 等待片刻，软件将自动启动并打开默认浏览器显示操作界面。

### 2.2 界面布局
软件界面主要分为两个区域：
- **左侧边栏 (Sidebar)**：控制面板，用于上传文件、全局设置、显示模式切换及参数配置。
- **右侧主屏 (Main Panel)**：数据展示区，包含概要信息、统计指标及详细的分析图表。

---

## 3. 核心功能与操作指南

### 3.1 加载数据 (Upload Data)
在左侧边栏的 **"上传分析数据文件"** 区域，点击 "Browse files" 或直接拖拽 JSON 格式的数据文件（例如 `analysis_data.json`）到上传框中。
> **注意**：数据文件必须符合特定的 JSON 格式标准（包含 `metadata` 和 `frames` 列表）。

### 3.2 数据过滤 (Data Filtering)
为了排除算法初始化阶段或极端情况下的异常数据干扰，软件提供了智能过滤功能。
- **功能位置**：左侧边栏 -> "🛡️ 数据过滤"
- **默认状态**：**开启**
- **作用**：当开启时，软件会自动隐藏以下数据点：
    - 算法置信度 (Confidence) 低于 0.5 的点
    - 算法输出距离为 0 的异常点
- **操作**：如果您需要查看所有原始数据（包括异常点），请手动关闭此开关。

### 3.3 图表显示模式 (Chart Modes)
您可以根据喜好调整图表的展示风格：
- **📈 折线图** (Lines)：不论是否存在数据点缺失，通过线条连接，适合观察趋势。
- **⚫ 散点图** (Markers)：仅显示离散的数据点，适合查看数据分布和缺失情况。
- **📊 折线+散点** (Lines+Markers)：同时显示线条和数据点，信息最丰富。

### 3.4 误差阈值配置 (Error Bounds)
您可以自定义各分析维度的误差容忍范围（红/蓝虚线），用于快速判断数据是否达标。
在左侧边栏的 **"误差上限/下限配置"** 区域，您可以调整：
- **距离误差** (默认 ±1.6m)
- **侧向/纵向误差** (默认 ±1.6m)
- **高度误差** (默认 ±1.6m)
- **光轴偏差角误差** (默认 ±1.5°)

## 4. 数据分析模块

软件主界面包含 6 个核心分析标签页：

### 4.1 综合概要
在页面顶部，您可以看到本次仿真的元数据，包括：
- 仿真 ID、生成时间
- 相机参数、环境配置
- **算法性能概览**：平均置信度、处理耗时
- **收敛指标**：初始误差、最终误差、RMS（均方根误差）

### 4.2 详细维度分析
点击对应的标签页即可查看详细分析：
1. **距离分析**：着舰距离 (Distance) 的对比及误差。
2. **侧向分析**：横向偏差 (Lateral) 的对比及误差。
3. **纵向分析**：纵向偏差 (Longitudinal) 的对比及误差。
4. **高度分析**：高度 (Height) 的对比及误差。
5. **偏航光轴偏差角**：Dyaw 的对比及误差。
6. **俯仰光轴偏差角**：Dpitch 的对比及误差。

### 4.3 图表交互功能
所有图表均支持交互操作：
- **查看数值**：鼠标悬停在曲线上，可显示具体的时间、真值、算法值及误差。
- **查看对应图片**：如果数据文件中包含图片路径，鼠标悬停时会显示**对应的图片文件名**，方便回溯原始图像。
- **缩放 (Zoom)**：在图表上拖拽框选区域，可放大查看细节。
- **复位**：双击图表区域即可恢复默认视图。
- **隐藏曲线**：点击图例（Legend）中的项目，可隐藏或显示特定曲线。
    - *注：误差图中的“拟合曲线”默认处于隐藏状态，点击图例即可显示。*

### 4.4 误差统计指标
在每个分析维度的下方，软件会自动计算并显示该维度的关键统计量：
- **最大误差**
- **最小误差**
- **RMS (均方根误差)**：评估算法整体精度的核心指标。

## 5. 常见问题 (FAQ)

**Q: 为什么图表中出现了很多断点？**
A: 这通常是因为您开启了"数据过滤"功能，算法置信度低的数据点被自动过滤了。尝试在侧边栏关闭过滤功能查看原始数据。

**Q: 为什么提示 KeyError: 'image_path'？**
A: 您的数据文件可能是旧版本格式，不包含图片路径信息。软件仅在数据包含此字段时才显示图片信息，但不影响其他分析功能。

**Q: 如何导出图表？**
A: Plotly 图表右上角有一个相机图标，点击 "Download plot as a png" 即可保存当前视图截图。
